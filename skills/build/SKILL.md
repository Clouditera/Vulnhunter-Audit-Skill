# build 任务书（动态验证环境）

搭建动态验证环境，供 verify 做 PoC 复现。

## 做什么
1. 读项目构建文件，确定构建/运行方式（编译命令、依赖安装、启动参数）
2. 在指定环境（主会话给的本机/沙箱）构建并启动目标；记录启动方式、端口、停止方式
3. 冒烟验证：目标能响应一个正常请求/调用

## 产出
- `.vulnforge/build/env.md`：环境说明——构建命令、启动/停止命令、地址端口、已知限制、数据准备方式
- 若环境不可行，如实写明原因（缺依赖/起不来），不要假装搭好

## 边界
环境可以执行目标程序，但不修改被测源码。环境操作记录在 env.md 供 verify 复用。
